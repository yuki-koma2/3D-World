# 3D Model Experiments

ブラウザで探索できる3D空間とプロシージャルモデリングの実験を、プロジェクトごとに公開するためのリポジトリです。

| プロジェクト | 内容 | 起動 |
| --- | --- | --- |
| [Aether City](projects/aether-city/) | 夕暮れの雲海に浮かぶ近未来都市。Orbitと物理付きWalkで探索 | `cd projects/aether-city && npm ci && npm run dev` |

各プロジェクトは独立した依存関係とREADMEを持ちます。作業データ、キャッシュ、ログはそのプロジェクト内に保存します。

共有先は [yuki-koma2/3D-World](https://github.com/yuki-koma2/3D-World) です。Webサイトへのデプロイは別途行います。
